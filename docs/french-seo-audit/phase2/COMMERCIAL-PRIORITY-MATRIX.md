## SCORING METHODOLOGY

Each page is scored 1–5 on six dimensions:

| Dimension | Description |
|-----------|-------------|
| **Revenue potential** | Expected revenue per month if page ranks top 3 (AOV × conversion × estimated traffic) |
| **Search demand** | Estimated French monthly search volume for primary keyword cluster |
| **Competition** | Inverse score — 5 = low competition (easy to rank), 1 = very high competition (hard to rank) |
| **Topical authority** | How much this page strengthens the site's topical cluster for its subject |
| **Internal-link value** | How many other pages this page can legitimately link FROM and TO |
| **Conversion impact** | Expected direct impact on enquiry rate if this page is built or improved |

Scores are summed (max 30). Pages are then grouped by priority tier.
