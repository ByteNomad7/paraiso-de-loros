## MISSING FRENCH CITY PAGES

The 50 FR city pages cover France's major urban centres comprehensively. No critical cities are missing.  
**Notable absences:** No regional landing pages (unlike ES which has pages for Andalucía, Cataluña, etc.). Consider:
- `/fr/perroquets-ile-de-france/` (Île-de-France region)
- `/fr/perroquets-provence-alpes-cote-dazur/` (PACA region)
- `/fr/perroquets-occitanie/`
- `/fr/perroquets-auvergne-rhone-alpes/`

Regional pages serve queries like "perroquet à vendre Île-de-France" which city pages don't capture.

## UNTRANSLATED OR MIXED-LANGUAGE CONTENT

- The site name "Paraíso de Aves" is Spanish; this appears throughout FR pages. This is acceptable as a proper brand name.
- "CITES" is consistent across languages (correct — it's an acronym).
- Schema `addressLocality: "Llíria"` and `addressRegion: "Valence"` correctly use FR spelling for Valencia.
- No mixed-language body content detected in audited pages; FR appears consistently in French.
- **Exception:** The footer/nav contains some elements inherited from the Spanish system — this should be verified on live pages.
