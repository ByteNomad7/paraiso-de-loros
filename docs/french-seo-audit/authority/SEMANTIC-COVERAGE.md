## OVERVIEW

Semantic coverage measures whether the site covers the full breadth of questions a user could ask about a topic. A site with 100% semantic coverage for "parrots" would answer every reasonable question a French speaker might have — from "what is a CITES" to "why does my parrot grind its beak."

Google uses semantic coverage as a proxy for topical authority. A site that answers 90% of the questions in a domain is treated as more authoritative than one that answers 40% — regardless of which specific pages rank for which queries.
