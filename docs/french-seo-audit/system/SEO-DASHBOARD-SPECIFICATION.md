# SEO Dashboard Specification — Paraíso de Aves FR

**Version:** 1.0  
**Date:** 2026-07-29  
**Purpose:** Define every metric, data source, calculation, and display format for the internal SEO dashboard  
**Implementation:** Node.js script reading the live filesystem + sitemap + HTML files. No external API required for core metrics.

---

## DASHBOARD ARCHITECTURE

The dashboard is a static HTML report generated by running:
```
node scripts/seo-dashboard.js > docs/reports/dashboard-[YYYY-MM-DD].html
```

It reads:
- `/sitemap_index.xml` + all split sitemaps
- All HTML files under `/fr/`
- `/_redirects`
- `/docs/qa-log.csv`

It outputs: a self-contained HTML file with charts, tables, and colour-coded health indicators.

## SECTION 2 — INTERNAL LINK HEALTH

### 2.1 Metrics

| Metric | Calculation | Alert threshold |
|--------|-----------|----------------|
| Orphan pages | Pages with < 3 inbound internal links | ANY orphan = RED |
| Average inbound links | Total link count ÷ total pages | < 5 = AMBER |
| Pages with no outbound links | Count HTML files with 0 `<a href="/fr/...">` | ANY = RED |
| Broken internal links | Links returning non-200 (test via HEAD request) | ANY = RED |
| Pages missing /fr/contact/ link | Count | > 10 = AMBER |
| Pages missing /fr/perroquets-disponibles/ | Count | > 20 = AMBER |

### 2.2 Link Graph Data

```js
// Build adjacency map: url → [outbound FR urls]
function buildLinkGraph(frPages) {
  const graph = {};
  for (const page of frPages) {
    const html = fs.readFileSync(page.path, 'utf8');
    const links = [...html.matchAll(/href="(\/fr\/[^"]+)"/g)].map(m => m[1]);
    graph[page.url] = [...new Set(links)];
  }
  return graph;
}

// Inbound count per page
function inboundCounts(graph) {
  const counts = {};
  for (const [src, targets] of Object.entries(graph)) {
    for (const t of targets) {
      counts[t] = (counts[t] || 0) + 1;
    }
  }
  return counts;
}
```

### 3.2 Schema Extractor

```js
function extractSchema(html) {
  const matches = html.match(/<script type="application\/ld\+json">([\s\S]*?)<\/script>/g) || [];
  return matches.map(s => {
    try { return JSON.parse(s.replace(/<script[^>]*>|<\/script>/g, '').trim()); }
    catch { return null; }
  }).filter(Boolean);
}

function schemaTypes(html) {
  const schemas = extractSchema(html);
  return schemas.flatMap(s => Array.isArray(s) ? s.map(x => x['@type']) : [s['@type']]);
}
```

### 4.2 Word Count Extractor

```js
function wordCount(html) {
  return html
    .replace(/<script[\s\S]*?<\/script>/g, '')
    .replace(/<style[\s\S]*?<\/style>/g, '')
    .replace(/<[^>]+>/g, ' ')
    .split(/\s+/).filter(w => w.length > 1).length;
}
```

## SECTION 7 — TECHNICAL SEO SCORE

Composite score 0–100 calculated as:

```
technical_score = (
  (orphan_pages_ok * 20) +           # 20 points: zero orphans
  (broken_links_ok * 20) +           # 20 points: zero broken links
  (schema_valid * 20) +              # 20 points: all schema valid
  (metadata_unique * 20) +           # 20 points: all titles + descs unique
  (images_ok * 10) +                 # 10 points: all images have alt + dimensions
  (mobile_cta_ok * 10)               # 10 points: mobile bottom bar present
)
```

Thresholds: 90–100 = 🟢 · 70–89 = 🟡 · < 70 = 🔴
